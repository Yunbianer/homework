## 四、结论与决议

1. **模块划分**：统一入口 index.html + 导航，自习室/统计为页内区块，三维为独立页面（three-d/scene.html）并设返回链接，保证不孤立。
2. **三维库选型**：A-Frame 采用**本地库**（three-d/libs/aframe.min.js），断网时三维场景仍可渲染，优先保证可用性。
3. **运行方式**：统计图表依赖 fetch(data.json)，受 CORS 限制无法在 file:// 下运行；决议提供 `serve.ps1` 一键起本地服务器，并在页面与 README 中明确说明，不强行兼容 file://。
4. **进度**：分三次提交推进——骨架 → 交互与图表 → 三维，每次提交后推送远程。
